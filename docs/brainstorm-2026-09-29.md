# Early AMOS brainstorming

Status: historical proposal, superseded by [VISION](VISION.md) and [RFC 0001](rfc/rfc-0001.md).

The early discussion considered an application foundation, operational tooling and autonomous maintenance. Subsequent requirements selected a complete new paid SaaS application, owner-controlled installations, a hybrid upgradable distribution, standard APIs/MCP and staged delivery. Earlier recommendations about an existing-app-first release or an application-level agent approval inbox are not current requirements.

The public planning record contains product requirements and independently reproducible public references only. Restricted source references and private planning context are excluded. No implementation or qualification is claimed by this note.
