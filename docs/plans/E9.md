# E9 -- CI, release artifacts and versioned application upgrades

fidelity: executable
Contract maturity: detailed draft; prerequisite and stage revalidation required. No task is execution-certified.

Acceptance: Untrusted contributions execute credential-free checks; privileged jobs only consume reviewed refs and exact artifacts. Podman-based artifact production, signed versioned distribution and source provenance are tested through real boundaries. Three-way upgrade fixtures cover unchanged managed files, owner edits, deletions, renamed files, package pins, workflow pins and migrations. External publishing, repository write permission and final combined live consumer evidence are explicit E16 gates.

Maintain packages, workflows and generator versions centrally while application owners retain business code and overrides. Ship local validation and ownership metadata early; upgrade automation later must produce reviewable changes, never silently overwrite custom code or merge itself.

All checkboxes describe future implementation. The complete inventory is intentional; later-stage tasks may not dispatch before their prerequisites and external gates.
