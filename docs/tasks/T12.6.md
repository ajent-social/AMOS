## Implementation instructions

1. Consume T2.9 signer/verifier through its public contract; this adapter owns transport propagation, not a second signing authority.
2. Create the frozen short-lived signed/encrypted service context with issuer/audience/expiry and request/workspace/actor bindings.
3. Provide a verification adapter/contract for a separate service without a universal cross-language agent protocol.
4. Support key rotation and bounded clock skew; never transmit raw user bearer/session credentials.
5. Test replay, wrong audience, stale context, changed request and disabled signing key through real HTTP verification.

- Replayed or altered context cannot authorize a different request/tenant.
