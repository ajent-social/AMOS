Status: PLANNED. Detailed draft, not execution-certified. Stage S3; wave 12; owning lane L13; estimate 90 minutes (planning hypothesis).

## Objective

Measure service health and asynchronous failures without unbounded labels.

## Implementation instructions

1. Expose latency/count/error metrics by bounded route/status and database pool saturation.
2. Add queue depth, oldest item age, retry count, dead-letter count and last-success metrics through module seams.
3. Keep identifiers, raw URLs, email addresses and organization IDs out of metric labels.
4. Bind metric access to local/private operator boundary and test cardinality bounds.
5. Implement the named verification cases at the real changed boundary; run the specified negative case in a disposable fixture, observe its predicted failure, restore the behavior, and record both results.

## Acceptance criteria

- A failing worker visibly increases failure/backlog signals.
- Arbitrary request paths cannot create unbounded metric series.
- Named scoped checks pass and the specified negative case is demonstrated; live/production qualification remains a separate explicitly authorized E16 gate where applicable.
