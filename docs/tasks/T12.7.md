## Implementation instructions

1. Implement bounded response/header forwarding, cookie/location rewriting rules and no cross-origin redirect following.
2. Apply declared streaming/upgrade support only for qualified routes; unsupported modes fail explicitly.
3. Propagate cancellation and distinguish pre-dispatch failure from unknown mutation outcome; never blindly retry writes.
4. Test slow headers/bodies, response overflow, reset connections, canceled streams and upstream redirects.
