## Implementation instructions

1. Pin PostgreSQL major/minor container digest and establish data, WAL and backup directories on the retained volume.
2. Bind only the private Podman network or loopback; provision separate runtime, migration and backup roles.
3. Configure restart policy, memory/connection limits, filesystem permissions and readiness checks.
4. Keep automatic major upgrades disabled and integrate backup preconditions before schema migration.
5. Implement the named verification cases at the real changed boundary; run the specified negative case in a disposable fixture, observe its predicted failure, restore the behavior, and record both results.
