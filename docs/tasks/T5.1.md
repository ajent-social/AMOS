## Implementation instructions

1. Specify flat monthly/yearly, seat and usage model combinations, currency minor units and versioned price catalog with no client-supplied prices.
2. Freeze billable-seat statuses, proration, trial/grace, payment-action, cancel/reactivate, refund/dispute and delinquency semantics.
3. Define usage occurrence/received time, period timezone, corrections, late-arrival cutoff and responsibility for tax/invoices; block unresolved money-impacting choices.
4. Define allowed/denied/unavailable entitlement result with freshness and reconciliation budgets; preserve account/recovery/billing routes.

## Acceptance criteria

- Policy tables fully describe each selected model and customer-visible transition.
- Unresolved prices/tax/grace/cancellation do not silently become production defaults.
