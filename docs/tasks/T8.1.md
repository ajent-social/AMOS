## Implementation instructions

1. Freeze machine profile identifiers aws_managed and aws_vm from the canonical configuration; managed and small-vm are display descriptions only. Record immutable selection in application and stack metadata.
2. Define managed ECS Fargate, private RDS PostgreSQL, HTTPS ALB and required Cloudflare DNS; compare explicit NAT versus endpoint/public-task egress and state the security/cost decision.
3. Define small-VM EC2, Podman, retained encrypted EBS, owner-hosted PostgreSQL and host HTTPS with no NAT/ALB unless explicitly selected; state single-AZ failure and patching responsibilities.
4. Estimate both for an explicit region/workload from current official pricing, including compute, database, disks, public IPv4, load balancing, egress, backups, logs and state; distinguish estimates from budgets.
5. Record exact size/architecture/image/database versions and classify profile switching as a separately planned migration; no implementation proceeds against an unresolved profile contract.

## Acceptance criteria

- Both profiles expose the same deployment/output contract but distinct resource and operation inventories.
- Profile contracts specify egress, availability, backups, deletion, cost and ownership; no per-installation price or topology is assumed.
