Status: PLANNED. Execution evidence is recorded below; release acceptance remains separate. Stage S3; wave 12; owning lane L08; estimate 90 minutes (planning hypothesis).

## Objective

Let developers customize any shared page while retaining stable action contracts.

## Implementation instructions

1. Load namespaced theme tokens/assets and selected owner templates through public composition configuration.
2. Validate declared UI contract version and required template/action slots at startup; fail on missing/incompatible overrides.
3. Keep escaping, CSRF action data and typed errors available to overrides without unsafe raw HTML conversion.
4. Build independent generated-consumer override fixture and browser tests for customized signin/checkout and escaped profile.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.

## Acceptance criteria

- One page can be fully overridden while remaining pages use default UI.
- Missing security/action slot or unsupported UI version fails explicitly before serving unsafe page.

Use cases: UC-047, UC-049.

## Negative verification

For behavior changes, show the check detects the predicted failure using a disposable isolated test mutation, then restore and report the passing check. Never damage a shared checkout or live environment. A design-only task uses a rejected schema/document fixture instead of pretending it changes runtime behavior.
