Status: PLANNED. Execution evidence is recorded below; release acceptance remains separate. Stage S3; wave 7; owning lane L14; estimate 60 minutes (planning hypothesis).

## Objective

Generate tool schemas from the frozen OpenAPI model without hand-written duplicate contracts.

## Dependencies and readiness

## Implementation instructions

1. Consume the generator intermediate representation through the T1.2 interface and emit sorted stable names/input/output descriptors.
2. Attach only reviewed operation metadata and reject unsupported parameter/body encodings.
3. Produce source-map diagnostics and an output manifest usable for upgrade review.
4. Add golden and repeated-generation tests including schema compatibility and forbidden exposure.

## Acceptance criteria

- Two generations from identical inputs are byte-identical.
- Generated descriptors validate against the frozen SDK/schema profile and omit private operations.
- Scoped checks, formatting and configured lint pass; E16 separately records any required deployed/live verification before this behavior is advertised.

Use cases: UC-080, UC-088, UC-095.

## Negative verification

Change an output field type or duplicate a tool ID; generation/check mode must fail with precise location.

For behavior changes, show the check detects the predicted failure using a disposable isolated test mutation, then restore and report the passing check. Never damage a shared checkout or live environment. A design-only task uses a rejected schema/document fixture instead of pretending it changes runtime behavior.
