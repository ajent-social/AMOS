## Implementation instructions

1. Define owner-scoped object references, bounded streaming, encryption requirements and expiry.
2. Use maintained provider SDK for S3 and a separate local test-only store.
3. Generate exports through authenticated lifecycle jobs; bind download authorization to current owner/request state.
4. Test missing object, expired export, cross-tenant request and delete/retention outcomes.
5. Serve exports through an authenticated AMOS download boundary with current-state checks. Do not use bearer presigned URLs when immediate revocation is required; define any later bounded-expiry exception explicitly.
