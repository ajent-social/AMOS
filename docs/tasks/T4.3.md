## Implementation instructions

1. Expose public transaction participant for identity signup and idempotent personal-workspace creation.
2. Bind immutable personal owner and prohibit membership invitation or conversion through organization APIs.
3. Add repair detection for historical incomplete bootstrap without silently granting extra ownership.
4. Test concurrent registration participant calls and failure between person/workspace writes.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.

## Acceptance criteria

- Committed account signup has exactly one owner-bound personal workspace.
- Rolled-back signup has no orphan workspace; another person cannot select it.

Use cases: UC-020, UC-033.
