Status: ACCEPTED. Execution evidence is recorded below; release acceptance remains separate. Stage S1; wave 6; owning lane L06; estimate 60 minutes (planning hypothesis).

## Implementation instructions

1. Define consumer-owned small interfaces for customer/checkout, subscription snapshot, portal, quantities and metering; explicit unsupported capability errors.
2. Namespace all provider objects by installation/environment/provider/account mode and workspace binding.
3. Define typed pending/unknown/confirmed/failed states, retry budget, idempotency duration and error classification.
4. Implement conformance fixtures exercising supported/unsupported operations and no-success-on-timeout.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.

## Acceptance criteria

- Unsupported meter/portal/seat capabilities return explicit errors before side effects.
- A lost provider response remains unknown until recovery proves outcome.
