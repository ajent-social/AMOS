Status: PLANNED. Detailed draft, not execution-certified. Stage S3; wave 27; owning lane L05; estimate 60 minutes (planning hypothesis).

## Objective

Make sensitive workspace administration observable without leaking credentials.

## Scope

- workspace/audit/**

Only these owned paths may change. Repository-qualified upstream paths require a separate upstream task claim and that repository's permissions/review rules; they are not permission to edit a neighboring checkout. ## Implementation instructions

1. Emit bounded actor/tenant/action/result events on invitation, role, ownership, enforcement and lifecycle changes.
2. Expose permission-controlled filtered audit listing with stable opaque cursor and tenant predicates.
3. Exclude token values, raw claims, seeds and customer data; use accepted retention policy and immutable event IDs.
4. Test real API pagination across timestamp ties, cross-tenant cursor injection and denied event access.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.

## Acceptance criteria

- All selected administration changes emit attributable sanitized audit events.
- Organization audit API cannot reveal another tenant even with copied cursor.
