## Implementation instructions

1. Freeze an EmailSender interface with secret references, bounded templates, recipient/privacy and error semantics.
2. Qualify AWS SES as the proposed initial provider using the maintained AWS SDK; keep selection visible if changed.
3. Send only from durable owned intents with backoff and unknown outcome handling.
4. Keep synthetic delivery in test-only injection and expose setup/unavailable when production sender is not configured.
