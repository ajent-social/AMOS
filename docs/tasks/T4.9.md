## Implementation instructions

1. Persist versioned OIDC client configuration with encrypted/reference-only secrets, issuer/client ID and exact callback mappings.
2. Require owner step-up and explicit domain verification challenge; domain proof enables configuration only, never auto membership.
3. Bound discovery/JWKS HTTP using approved issuer policy and egress controls against internal metadata/private targets.
4. Test API unauthorized setup, malicious discovery URL, stale domain proof and secret-safe reads.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.
