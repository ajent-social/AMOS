Status: PLANNED. Detailed draft, not execution-certified. Stage S1; wave 11; owning lane L06; estimate 90 minutes (planning hypothesis).

## Objective

Converge provider snapshots after duplicate, missing and unordered events.

## Implementation instructions

1. Read official provider current subscription/items for bound customer/account/mode under bounded retry and rate limits.
2. Apply snapshot with version/lease check, known price map and freshness; reject ambiguous multiple subscriptions under frozen policy.
3. Process durable dirty customers and unmatched events; periodic scan catches missed webhooks, with checkpointed resumable batches.
4. Test older event after newer provider state, cancellation/new subscription replacement, response loss and stale-worker CAS.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.

## Acceptance criteria

- Event arrival order cannot reverse the authoritative current provider snapshot.
- Missed webhook converges on next scheduled reconciliation; provider outage produces stale/unavailable access per policy.

Use cases: UC-040, UC-041, UC-045.
