## Implementation instructions

1. Provision the frozen VPC/subnet/route profile with explicit public address choice and no default NAT.
2. Allow public 80/443 only for direct origin TLS; do not expose SSH or database ports.
3. Create an instance role for selected image pull, scoped application secret access, backup writes and management access.
4. Test IAM resource scoping and separate runtime permissions from provisioning permissions using Pulumi mocks.
5. Implement the named verification cases at the real changed boundary; run the specified negative case in a disposable fixture, observe its predicted failure, restore the behavior, and record both results.
