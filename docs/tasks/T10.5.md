## Implementation instructions

1. Use the frozen OpenTelemetry propagation/export contract with configurable sampling and bounded queue.
2. Create app/database/outbound spans using sanitized names and no SQL parameters or request payloads.
3. Authenticate/allowlist exporter destinations and disable external export unless configured.
4. Test exporter outage, cancellation and cross-service context propagation.
5. Implement the named verification cases at the real changed boundary; run the specified negative case in a disposable fixture, observe its predicted failure, restore the behavior, and record both results.

## Acceptance criteria

- Exporter failure cannot block normal request completion or exhaust memory.
- Trace attributes contain no session, billing or credential values.
- Named scoped checks pass and the specified negative case is demonstrated; live/production qualification remains a separate explicitly authorized E16 gate where applicable.
