## Implementation instructions

1. Load explicit server-side plan/price versions and currency/model metadata from reviewed config; reject unknown/deleted prices.
2. Map verified subscription item/price/status/period/freshness to typed entitlements and explainable reason codes.
3. Keep access to account, recovery and billing restoration available when business entitlement denies.
4. Test period boundary, stale/missing projection, wrong price and monthly/yearly versions without wall-clock sleeps.
