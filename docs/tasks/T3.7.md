## Implementation instructions

1. Implement origin/CSRF validation for cookie-authenticated mutations using frozen proxy and callback exceptions.
2. Apply shared durable rate limits by bounded combinations of IP, account key and operation, preserving generic enumeration-resistant responses.
3. Validate post-auth relative redirect targets and headers; cap request bodies and expensive password/challenge work.
4. Test cross-site registration/session actions, redirect variants, proxy-header spoofing and concurrent limit exhaustion.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.
