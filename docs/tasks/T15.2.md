## Acceptance criteria

- No credential mode grants broader authority than current application policy.
- Every advertised sensitive operation has a cross-tenant and privilege-escalation denial assertion.
- Scoped checks, formatting and configured lint pass; E16 separately records any required deployed/live verification before this behavior is advertised.

## Negative verification

Keep a valid OAuth token after role downgrade and call an admin action; request is denied without effect.

For behavior changes, show the check detects the predicted failure using a disposable isolated test mutation, then restore and report the passing check. Never damage a shared checkout or live environment. A design-only task uses a rejected schema/document fixture instead of pretending it changes runtime behavior.
