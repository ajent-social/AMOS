## Implementation instructions

1. Wrap the qualified hashing library; store version/parameters/salt/hash and reject malformed or oversized hashes before expensive work.
2. Implement verify plus opportunistic rehash after successful proof; preserve credentials when rehash persistence fails.
3. Apply frozen password length/encoding rules and constant-work unknown-user verification within bounded resource policy.
4. Test wrong secret, legacy parameter upgrade, malformed encodings and resource limits without copying crypto.
5. Format touched Go files with gofmt and changed frontend files with the pinned formatter; run scoped vet/lint and the named behavioral checks, rejecting skipped or zero matching tests.
