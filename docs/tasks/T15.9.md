## Scope

- internal/releaseattest/*
- tests/fixtures/releaseattest/*

## Implementation instructions

1. Verify signatures/identity/trust policy and compare source, workflow, dependencies, check-set and artifact digests to the eligible decision.
2. Reject missing/expired/revoked/untrusted evidence and disallow mutable artifact references.
3. Cache verification only by immutable evidence plus trust-policy revision with bounded revocation semantics.
4. Test substituted artifacts, forged subjects, valid signatures from wrong jobs and stale policy/cache replay.

## Acceptance criteria

- Any digest/identity/policy mismatch blocks promotion even with a valid signature.
- Revoked builder identity or changed policy invalidates cached eligibility.
- Scoped checks, formatting and configured lint pass; E16 separately records any required deployed/live verification before this behavior is advertised.

Use cases: UC-100, UC-114, UC-115.

## Negative verification

Replace the verified image under a mutable tag with a different digest; release verifier must refuse it.

For behavior changes, show the check detects the predicted failure using a disposable isolated test mutation, then restore and report the passing check. Never damage a shared checkout or live environment. A design-only task uses a rejected schema/document fixture instead of pretending it changes runtime behavior.
